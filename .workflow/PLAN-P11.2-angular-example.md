# _`P11.2`_ The `angular` showcase adapter example

implemented 2026-11-14 (option chosen: "Approve and commit (Rec.)"; _`D473`_); approved 2026-11-14 (option chosen: "Approve and commit (Rec.)"), without a zero-context review; choices _`D469`_–_`D472`_ settled 2026-11-14

## Goals

The `angular` showcase adapter's example, as every new showcase adapter has (_`D304`_ (SPEC.md)), as _`P11`_ (PLAN-P11-angular.md) scopes it: `examples/angular/README.md`, a mock project on the examples' theme (_`D312`_ (SPEC.md)), depending only on this repository's own dependencies, with a `tsconfig.json` of its own (_`D307`_ (SPEC.md)); its first showcase a linked showcase of a real file, shown as a block in `README.md` too (_`D315`_ (SPEC.md), _`D410`_ (PLAN-P10.4-code-pane.md)); `README.md`'s `angular` part linking to the example's other showcases by their headings, relatively and in the published showroom (_`D309`_, _`D314`_ (SPEC.md)); this repository's own `check --showcases` building it (`ci:showroom`, and `src/cli/check/index.integration.test.ts`).

No child segments: the example only uses what _`P11.1`_ (PLAN-P11.1-angular.md) built.

## Decisions

Settled 2026-11-14 in one dialog, Q1–Q4.

- _`D469`_ (`live`; Q1; changes _`D312`_ (SPEC.md), its `angular` part, whose "the same pickers in Angular" assumed `react`'s example would be number pickers; it became `ticker`, _`D350`_ (PLAN-P7.2-react.md)): **`examples/angular/` mirrors the `react` example's `ticker`**: a made-up Angular component library, `tock`, of a stopwatch, counters stepping between bounds, and following the theme, written the Angular way (standalone components, signals, signal inputs and outputs, a root service, templates), so readers compare the two showcase adapters on the same subject (option chosen: "Mirror ticker (Rec.)"). Rejected: number pickers (a digit wheel, an odometer, a dial: new widgets with no counterpart to compare with); another subject in the theme.
- _`D470`_ (`live`; Q2): **What the example shows**, beyond the basics (signal inputs and an output logging to the console panel, a root service, following the theme, a standalone pipe of `@angular/common`, e.g. `DecimalPipe`): the library's stopwatch keeps its template and styles in real files (`templateUrl`, `styleUrl`), rendered by the first showcase; a showcase whose `templateUrl` names a virtual ` ```html showcase file=… ` resource; and one showcase with the `zone` option (`showcase=angular({ zone: true })`), its component `ChangeDetectionStrategy.Eager`, refreshed by zone-based change detection after a plain field changes (options chosen: "templateUrl/styleUrl files (Rec.)", "Virtual template (Rec.)", "zone option (Rec.)"). Rejected: an NgModule import (legacy for new code; the `showcase-angular` fixture covers it, _`D464`_ (PLAN-P11.1-angular.md)).
- _`D471`_ (`live`; Q3; resolves _`O80`_ (PLAN-P11-angular.md)): **`README.md`'s copy of the first showcase is type checked with the root `tsconfig.json` as it is**, as its `react` copy already is: the program is the entry point and the tsconfig's declaration files (_`D453`_ (PLAN-P11.1-angular.md)), and `@Component` classes type check without `experimentalDecorators` (found in _`P11.1`_); `ci:showroom` and the `integration` test fail on any break. Its templates are checked without `strictTemplates` there, and with it in the example's own copy (_`D472`_) (option chosen: "Root tsconfig as is (Rec.)"). Rejected: `angularCompilerOptions` in the root `tsconfig.json` (the example's settings mixed into the repository's own configuration).
- _`D472`_ (`live`; Q4; refines _`D307`_ (SPEC.md)): **`examples/angular/tsconfig.json`** holds the other examples' options (`types: []`, `strict`, `noEmit`, `module: esnext`, `moduleResolution: bundler`, `isolatedModules`, `lib` with the DOM), and the `angularCompilerOptions` `ng new` sets: `strictTemplates`, `strictInjectionParameters`, `strictInputAccessModifiers`; no `experimentalDecorators` (option chosen: "Strict, as ng new (Rec.)"). Rejected: no `angularCompilerOptions` (templates checked less strictly than a real host's).

- _`D473`_ (`live`; from _`P11.2`_'s checkpoint, option chosen: "Approve and commit (Rec.)"): **_`P11.2`_'s deviation from its steps, approved**: step 5's integration test changed after all, its list of the examples' showcase adapters gaining `angular`; `CONTRIBUTE.md`'s list of the examples also gained the missing `react/`.

## Steps

1. **The library**, `examples/angular/src/`: the stopwatch component (`stopwatch.component.ts`, its `.html` and `.css`, the styles following the theme with CSS's `light-dark()`), the counter component (inline template; signal inputs `label`, `start`, `step`, `min`, `max`; an output on change), the theme service (`providedIn: 'root'`, a signal of the showroom's theme from `<html>`'s `data-showroom-theme`, followed with a `MutationObserver`, falling back to the system's theme), and the formatting of elapsed times; `examples/angular/tsconfig.json` (_`D472`_).
2. **The example**, `examples/angular/README.md`, on the `react` example's outline: the intro (a made-up Angular library, and the `angular` showcase adapter's example; its files real, type checked with this folder's `tsconfig.json`, compiled with this repository's own Angular); **A stopwatch**, the linked `demo/stopwatch.ts` shown as a block (_`D315`_); **Counters**, a code block showcase with inputs and the output logging to the console panel; **Following the theme**, through the root service; **A shared template**, a virtual `laps.html` resource, then **Composing**, a showcase whose `templateUrl` names it, holding state of its own and formatting with `DecimalPipe` or the library's formatting; **With zone.js**, the `zone` option (_`D470`_). Headings may change while writing; `README.md`'s links follow them.
3. **`README.md`**: the `angular` part ends as the `react` part does: the example named and linked (relatively and live), its first showcase linked as a showcase shown as a block (`showcase=angular block`), and the links to its other showcases by their headings, twice each; the README's own `ts` sample code block stays as it is.
4. **`AGENTS.md`** (the layout's `examples/` line, the gotcha "Markers in this repository's own documentation files are live" if it lists the examples) and **`CONTRIBUTE.md`** (the project structure, if it lists the examples), kept current; Markdown formatted as the workflow says.
5. **Tests**: no new test file: `src/cli/check/index.integration.test.ts` already runs `check()` with `showcases: true` on this repository (every live showcase, and the example's type checking, built) and checks `README.md`'s links into the examples against their headings; run it, and `npm run ci`.
6. **Verification**: `npm run ci` green; the dogfood `serve` restarted, for the user's browser check at the checkpoint: the example's showcases rendering and updating (the stopwatch, the counters' console lines, the theme switch, the composed laps, the zone showcase), and `README.md`'s copy of the stopwatch.
